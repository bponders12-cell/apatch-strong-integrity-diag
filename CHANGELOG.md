# Changelog

## v1.4.0 (2026-10-26)
- **Fixed False-Positive CRL Substring Match**: Updated WebUI `keybox_xml` check from `.indexOf("revoked")` to `.indexOf("revoked_")` so `clean_unrevoked` hardware keyboxes evaluate to `[PASS]`.
- **PlayIntegrityFork v15+ `migrate.sh` Schema Support**: Updated `scripts/diag_engine.sh` to recognize `*.build.id=`, `*.security_patch=`, and `*api_level=` generated by `migrate.sh`.
- **Live Canary Print Crawler Integration (`autopif4.sh -s -m`)**: Updated `scripts/apply_fix.sh` to invoke PlayIntegrityFork's `autopif4.sh -s -m` first so Pixel devices (such as Pixel 8a `akita_beta`, SDK 34 <= 35) pull a live, non-expired Canary print directly from Google's FlashStation API and sync `/data/adb/tricky_store/security_patch.txt`.

## v1.3.0 (2026-10-25)
- **Pure-BusyBox ASN.1 DER Certificate Parser**: Replaced `/system/bin/openssl` dependency with a pure-BusyBox `base64 -d` + `od -An -tx1` + `awk` ASN.1 DER serial parser that extracts all certificate serial numbers from `keybox.xml` on stock Android.
- **ReZygisk vs. APatch `package_config` Unblocker**: Detects and removes `com.google.android.gms,1,...` (`Exclude Modifications`) entries from `/data/adb/ap/package_config` when ReZygisk/ZygiskNext is used without a separate root-hider module.

## v1.2.0 (2026-10-25)
- **1-Tap `Fix for Me` Auto-Remediation**: Added `scripts/apply_fix.sh` and per-card **Fix for Me** buttons in the WebUI via `window.ksu.exec()`.

## v1.1.0 (2026-10-25)
- **PIF `.prop` & Pixel 10/11 RKP Detection**: Added support for `custom.pif.prop` and detection for `DEVICE_INITIAL_SDK_INT >= 36` (`frankel`, `blazer`, `mustang`, `rango`) RKP enforcement.

## v1.0.0 (2026-10-25)
- Initial 6-layer diagnostic engine (`scripts/diag_engine.sh`) and interactive APatch WebUI (`webroot/index.html`).
